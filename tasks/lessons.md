# Lessons

- 2026-05-19: In the Aegis-Manim dual-coding result UI, rendered video and synchronized script must be a left-right comparison on desktop. Stack them only on narrow or mobile layouts.
- 2026-05-20: In Chinese-community teaching flows, visible Manim scene text should default to Chinese; keep English symbols only as compact variables and explain them in Chinese.
- 2026-05-20: Formula-heavy prompts need two layers: the Manim video path stays LaTeX-free with `Text(...)`, while the Web learning-script layer can render Markdown/LaTeX-style formulas for readability.
- 2026-05-23: Do not declare Aegis-Manim production usable from a single successful render. Run repeated closed-loop tests that include model generation, Render job completion, MP4 byte validation, community publish/search/reuse/rating, and feed every observed generated-code runtime failure into `apply_runtime_compatibility_fixes` with regression coverage before rerunning acceptance.
- 2026-05-24: For Aegis-Manim, "video rendered" is not enough. Every production acceptance run must use a real subject prompt, download the MP4, extract at least one frame, and verify the visual content matches the prompt; fallback templates need topic-specific teaching scenes rather than generic step cards.
- 2026-05-24: For public trial model routing, expose only non-sensitive provider diagnostics in `/api/health` before guessing. A Kimi Coding Plan key can be configured but still fail with `access`; MiniMax can be configured but still exceed the Vercel generation timeout. Keep fallback render quality high and report failure categories without logging secrets.
- 2026-05-24: Topic fallback routing must use narrow semantic triggers. Generic economics words like demand/supply/cost cannot imply a tax-wedge scene; every new economics fallback needs a negative test proving nearby topics do not route to the wrong template.
- 2026-05-24: For friend-facing Aegis-Manim releases, quality means topic match plus Manim API compatibility plus frame-level visual inspection. Official/community rules must be encoded as prompt constraints, precheck rules, regression tests, and at least one downloaded-frame review before claiming a cloud render is acceptable.
- 2026-05-25: For Chinese economics fallback templates, add topic-priority tests and a live frame review after deployment. Prompts can mention both the target topic and nearby concepts such as deadweight loss, so the fallback order must preserve the intended topic and the final frame must be checked for label overlap, not just successful rendering.
- 2026-05-26: For Aegis-Manim multi-lane production work, write the Agent Team lifecycle into the task trail. Call Agent Team for independent discovery, provider/server comparison, acceptance design, or pre-production critique; reclaim to the lead agent for code edits, packaging, secrets, deployment commands, and user-intervention steps; call it again only after a material state change such as a real server doctor result; close it once evidence is merged into `tasks/todo.md` or the relevant component document.
